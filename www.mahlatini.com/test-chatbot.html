Checking... Widget: WebSocket + REST fallback

The chat widget (bottom-right) connects via WebSocket to the API. If WebSocket fails, it automatically falls back to REST. Lead capture, intent classification, and n8n webhook forwarding are all active.

API Endpoints

  • GET /health — System health check
  • POST /api/chat/message — REST chat (fallback)
  • WS /api/chat/ws/{session_id} — WebSocket chat
  • POST /api/chat/n8n-callback — n8n push notifications (NEW)
  • GET /api/chat/n8n-pending/{session_id} — Poll pending messages (NEW)
  • POST /webhook/new-enquiry — Lead capture to n8n
  • POST /webhook/website-enquiry — Form submission to n8n
